# Project Agent (AGENT.md)

## Structure
- SvelteKit 2 + Svelte 5 runes (`$state`, `$derived`, `$props`) running on Bun 1.4+. `src/routes/+layout.ts` owns `export const ssr = false` for every route.
- Deploys to Cloudflare Pages via `@sveltejs/adapter-cloudflare` (output `.svelte-kit/cloudflare`, build command `bun run build`). Since nothing is server-rendered, the only code in the Pages Function is `/api/ai*`; the `nodejs_als` compatibility flag is required for the AI SDK (it uses `AsyncLocalStorage`). No environment variables — the selected Gemini or OpenRouter key arrives per-request with `x-ai-provider`, `x-ai-api-key`, and `x-ai-model-id`.
- Core Modules:
  - `src/lib/table/`: `DataTable.svelte`, `TableCellContextMenu.svelte`, `TableFilterMenu.svelte`, `TableColumnMenu.svelte`, `DropdownCellEditor.svelte`, `FormulaHintPopup.svelte`, `store.svelte.ts`, `find.svelte.ts` (pure scanner + find/replace store), `documents.svelte.ts` (multi-file index), `source-files.ts` (IndexedDB binary storage for attached files), `cells.ts` (`isBlank`, alignment, numeric checks), `formulas.ts` (evaluation + reference remapping), `formula-hints.ts` (completion catalog + caret logic), `range-edit.ts`, `commands.ts`, `schema.ts`, `persistence.ts`, `filters.ts` (per-column value-list & condition evaluation; `filteredRows` is the single funnel). The header shows a filter button per column next to the sort control, sharing the column-menu's floating positioning and design tokens; the filter state is view-only session state (not persisted — see below).
  - `src/lib/components/`: `Header.svelte` (Files switcher + title + search + alignment control + source files badge), `RightRibbon.svelte` (AI, find/replace, source documents, modules, add row, export, theme, settings — **not** file creation or import), `AiDrawer.svelte`, `FindReplaceDrawer.svelte`, `SourceViewerDrawer.svelte` (native browser PDF & spreadsheet split viewer), `Icons.svelte`, `settings/` (`AiSection.svelte`, `ModulesSection.svelte`, `ShortcutsSection.svelte`) — rendered on the `/settings` page behind a three-item section rail (`nav.settings-sidebar`), not a modal.
  - `src/lib/modules/`: `types.ts`, `registry.ts`, `module-store.svelte.ts`, `icegrid/` (`index.ts`, `pipeline.ts`, `columns.ts`, `readers.ts`, `schema.ts`, `extract.ts`, `ai.server.ts`, `evidence.ts`, `sanitize.ts`, `derive.ts`, `validate.ts`, `to-table.ts`, `profile.ts`, `confirm.ts`, `confirm.client.ts`, `exchange-rate.ts`, `tariff.ts`, `tariff.server.ts`, `duty-lookup*.ts`, `IcegridSettings.svelte`, `IcegridConfirmDialog.svelte`, `catalogs/`, `rules/`).
  - `src/lib/server/`: `ai-provider.ts` (Gemini/OpenRouter AI SDK model factory) and `modules/` (server-only AI handler types + static module action registry). `src/lib/ai/providers.ts` owns shared provider ids, labels, profiles, and provider-aware model validation.
  - `src/lib/data/`: `import.ts`, `export.ts`, `index.ts`. There are no sample datasets — a new workspace opens a blank file.
  - `src/lib/ai/`: `client.ts`, `patches.ts`, `settings.svelte.ts` (dedicated provider, API keys, and favorites settings store, decoupled from table data).
  - `src/lib/ui/`: `position.ts`, `combobox.ts`, `menu.ts`, `ToastHost.svelte`, `toast.svelte.ts`.
  - `src/lib/workspace.svelte.ts`: the single shared document/table/module/toast store + theme, owned above the router so `/settings` and `/` share one live workspace. `createFile`/`newBlankFile`/`openFile`/`deleteFile` are the only entry points that switch files.
  - Root: `src/lib/constants.ts`, `src/lib/types.ts`.
- `src/app.d.ts` exists only to declare the untyped `xlsx-calc` module. Nothing else belongs in it.
- Routes: `src/routes/+layout.svelte`, `src/routes/+page.svelte` (workspace), `src/routes/settings/+page.svelte` (settings; active section is local state, no URL param), `src/routes/api/ai/+server.ts`, `src/routes/api/ai/models/+server.ts`, `src/routes/api/icegrid/duty-lookup/+server.ts`, `src/routes/api/icegrid/exchange-rate/+server.ts`, `src/routes/api/icegrid/tariff-search/+server.ts`.
- Styling: Tailwind CSS v4 (`@tailwindcss/vite`) in `src/app.css` providing utility classes, non-black ultra-thin scrollbars, and design tokens across dark/light themes.
- Document shape: `TableData` is `{title, columns, rows, cellAlign?, sourceText?}`. `DocumentMeta` has `sourceFiles?: string[]`. `cellAlign` maps `rowId::columnId` to `left|center|right` and is part of the persisted v2 document, the undo history, and the document hash. `sourceText` preserves raw extracted document text across sessions and forwards to the AI assistant for shipment context (buyer/seller, containers, POs, terms).
- Storage layout: `xlsx-ai:docs:v1` holds `{docs:[{id,title,updatedAt,sourceFiles?}], activeId}`; each file's rows live at `xlsx-ai:doc:<id>`. Binary attachments (PDFs, spreadsheets) are stored in IndexedDB (`xlsx-ai-files` database, `source_files` store) keyed by `${docId}:${filename}` and cleaned up on document deletion. The table store takes its storage key as a getter so the active file can change without rebuilding the adapter.
- Cursor mode & selection: `store.svelte.ts` holds single `selection = $state<CellSelection | null>(null)` (`{anchor, focus}`) and `cursorMode`. Rectangles are **derived** (`selectionRect`), never stored, so a sort or search re-clamps them instead of leaving indexes pointing past the end of `filteredRows`; `selectionKeys` is the flat `rowId::columnId` set every consumer should scope by (Find & Replace does). Cursor mode, toggled beside cell alignment in `Header.svelte`, makes a single click place a caret in the cell (`caretRangeFromPoint`, text columns only) rather than select it. `Esc` collapses a range selection to its focus cell.
- Tests: `tests/app/*.test.ts` (host app: table, documents, data, formulas, ai, modules framework) and `tests/icegrid/*.test.ts` (the ICEGrid module, with its corpus fixtures under `tests/icegrid/fixtures/`), run via `bun test`; `e2e/table.spec.ts` runs via `bun run test:e2e` (chromium only). One directory per module under `tests/` — keep module tests out of `tests/app/`.
- Verification & Health Tooling:
  - Type checking: `bun x tsc --noEmit && bun run check` (`svelte-check` for Svelte diagnostics, `tsc` for pure TypeScript).
  - Dead code & deprecation scan: `bun x knip` (flags unused exports, dead files, types, and orphaned deps) and `bun x oxlint`.
  - Dependency diffing & licenses: `bun pm diff <pkg>` (inspect package version changes) and `bun pm licenses`.

## Blunders
- `caretRangeFromPoint` returns a range anchored on the parent element when clicking cell padding. Fixed by checking `nodeType === Node.TEXT_NODE` and restricting 1-click caret to text columns.
- Storing selection rectangle directly in state caused desyncs on filter/sort. Fixed by computing `selectionRect` as `$derived.by` from visible rows.
- Direct import of `pdfjs-dist/build/pdf.mjs` throws `ReferenceError: DOMMatrix is not defined` in headless Bun tests. Fixed by importing from `pdfjs-dist/legacy/build/pdf.mjs`.
- `bind:this` on Svelte 5 elements with inline arrow functions fails `svelte-check`. Fixed with custom Svelte action `use:registerCellNode`.
- Empty/0-row tables reset to sample data on reload because `store.rows.length === 0` was ambiguous. Fixed with explicit hydration status `{ status: 'restored' | 'missing' | 'invalid' }`.
- Exporting tables with duplicate column names dropped data on plain object mapping. Fixed with `buildUniqueExportHeaders()`.
- Gemini `responseSchema` rejects non-string enums and `z.literal(number)` with HTTP 400. Fixed by stripping metadata literals and stamping `reportVersion` server-side.
- `.min(1)` in Gemini extraction schema caused 502 on packing-lists without invoice lines. Fixed by permitting 0 rows and quoting model warnings.
- `min-width: max-content` on `table-fixed` tables renders ~18M px wide in Firefox. Fixed by computing explicit pixel width `gridW` plus `min-width: 100%`.
- Firefox expands unconstrained table rows under `height: 100%`. Fixed by setting `h-8` on header and keeping `tr.grid-filler` as the sole unconstrained row.
- Focus event between mousedown and click collapsed Shift-selections. Fixed by setting `pointerExtend` in `onmousedown` for `onfocus` to read.
- `$effect` implicitly returning `registerImportPicker` ran file-picker on component unmount. Fixed by using braced effect bodies with explicit cleanup.
- File creation and import were duplicated in the ribbon. Fixed by keeping them exclusively in the header Files menu.
- Store serialized entire document on every reactive read for unused `isDirty`. Fixed with shallow snapshot cloning for history.
- Failed `localStorage` write failed silently. Fixed by passing `onSaveError` callback to trigger workspace toasts.
- `deleteFile` switching active document before debounced pending write flushed corrupted survivor document. Fixed with `store.flushSave()` at top of `deleteFile`.
- Eager import of ICEGrid schedules bloated initial bundle. Fixed by dynamically importing `pipeline.ts` on module run.
- Excel numeric formatting `#,##0.##` rendered trailing dots on integers. Fixed by leaving raw numbers unformatted for General formatting.
- Switching `sheet_to_json` to `raw: true` for precision silently cost every currency, percent and date column its type. Fixed by inferring type from `.w` string and keeping raw value.
- Verification span parser failed on non-contiguous text in multi-column PDFs. Fixed with token overlap verification.
- DGFT tariff search matches literally without stemming. Fixed by asking model for search phrases in tariff vocabulary, never raw codes.
- Item keys generated with commas/quotes failed model echo-back. Fixed by using short opaque IDs (`i0`, `r0`) and mapping server-side.
- Tariff search query budget starved tail items. Fixed by allocating queries round-robin across items.
- Duty-structure cache keyed per-item retained stale serials on code switch. Fixed by keying cache per-code (`dutyByCode[code]`).
- Ranking candidates by shortest description biased toward residual "Other" codes. Fixed by penalizing residual entries and sorting by token prefix overlap.
- Regular expression with `/g` flag retains state across `.test()` via `lastIndex`. Fixed by using non-global regexes for testing and global regexes only for replacement.
- `parseNumeric` parsed arbitrary text containing digits as numbers. Fixed with strict regex validation `^[+-]?(?:\d+\.?\d*|\.\d+)(?:[eE][+-]?\d+)?$`.
- `commands.ts` coupled dropdown resolution using pre-batch row prevented parent-child updates in single batch. Fixed by resolving options against effective row with incoming patches (excluding current column).
- AI SDK error logging printed complete error objects with document bodies to logs. Fixed by sanitizing to `{ requestId, model, statusCode, isRetryable }`.
- Non-interactive `agy --print` runs hit an internal 300s socket timeout when reasoning effort is high on broad tasks. Keep briefs narrow or avoid unbounded single-turn code generation.
- Svelte 5 effect reading/writing blob URL state in drawer caused infinite reactive loop (maximum update depth exceeded), freezing grid and menus. Fixed with pure effect teardown `return () => URL.revokeObjectURL(url)`.
- Cell `onfocus` firing on right-click mousedown collapsed multi-cell selections before context menu opened. Fixed by skipping focus collapse when target cell is in `selectionKeys` or right-clicked.
- Number parsing in `to-table.ts` and `derive.ts` stripped leading `=` on numeric formula expressions (`=M2` -> `null` or `2`). Fixed by preserving strings starting with `=` before parsing floats.

## Notes & Discoveries
- **ICEGrid rules architecture**: All customs filing domain logic (schemes, drawback gating, quantity formulas, address geography, tax arithmetic) is encapsulated inside `src/lib/modules/icegrid/rules/`.
- **ICEGrid drawback and quantity formulas**: Scheme 00 is non-drawback (leaving RewardItem and RoDTEP selectable). On drawback schemes, an empty `dbk_unit` inherits `QuantityUnit`. `dbk_qty` uses formula `=O{row}` if `dbk_unit` matches `SQCUnit`, `=M{row}` if it matches `QuantityUnit` or if `dbk_unit` is empty, or `Quantity` as default.
- **Confirmation dialog**: `pipeline.ts` runs `deriveRows` before confirmation to generate proposals, and re-derives over confirmed answers so downstream fields recompute. Dialog asks per unique RITC plus invoice-wide block.
- **Exchange rate**: `impexcube.in/Home/LoadExRate` GET endpoint supplies the board. Always use `Export` column (never `Import`). Scanner detects currency from document text, excluding `INR`.
- **Formulas evaluation**: Evaluated via `xlsx-calc` into `store.resolvedRows` (editor uses `store.rawCell()`). `normalizeCellValue` passes `=`-prefixed text through untouched.
- **Formula reference remapping**: `remapFormulaRefs` and `offsetFormulaRefs` handle structural shifts and fills; `$`-pinned references adjust on insert/delete but stay pinned on fill.
- **Formula export addressing**: Header is row 1, data starts row 2. `write-excel-file` expects expressions without leading `=` (`value: 'SUM(...)'`).
- **Spreadsheet libraries**: `xlsx` (SheetJS CE) is used exclusively for reading (`.xls` support). `write-excel-file` is used exclusively for writing (styling without heavy Node shims).
- **CSV sanitization**: Export prefixes values starting with `=`, `+`, `-`, `@`, `\t`, `\r` with `'` to prevent spreadsheet injection.
- **Color tokens & Tailwind**: All colors use CSS variables (`--accent-*`, `--surface-*`) in OKLCH; never use hardcoded Tailwind palette classes (e.g. `text-emerald-400`).
- **Font variables**: `--font-sans` and `--font-mono` must be declared in `@theme` in `src/app.css` (inert if placed in `:root`).
- **Theme surface hierarchy**: Light mode is `bg < surface-2 < surface-1`; dark mode is `bg < surface-1 < surface-2`.
- **Cell alignment**: Stored in `TableData.cellAlign` (`rowId::columnId -> left|center|right`). Pruned on sanitize and forwarded to `.xlsx` export.
- **Roving tabindex & Popovers**: Grid cells use roving `tabindex="0"/-1`. Table popovers use `position: fixed` via `computeFloatingPosition()`.
- **Coupled dropdowns**: `DropdownOption.fills` and `fillsIfBlank` expand in `commands.ts` (one hop, never cascade). Options resolve via `resolveDropdownOptions(col, row, rows)`.
- **Internal columns**: Columns marked `internal: true` (e.g. `NetWeight`) are excluded from grid/export but preserved for derivation rules.
- **Cleared headers**: `Accessories` and `Total_Package` are cleared mechanically and excluded from extraction schemas.
- **Column filters**: In-memory view-only session state (`columnFilters`) evaluated in `filteredRows` funnel; never persisted in document or history.
- **Find & replace**: Keybinding is `Cmd/Ctrl+H`. Literal replacements escape regex specials; matches scan raw `storageRow` strings for 1-step atomic undo.
- **AI copy buttons**: Messages render copy buttons post-stream; SVG responses include a dedicated button extracting balanced `<svg>...</svg>` markup.
- **E2E testing**: Always run with `bun run test:e2e` (targets fresh build via `vite preview`), never bare `playwright test`.

## Workspace Module Rules
- Register browser modules only in `src/lib/modules/registry.ts`; register server AI actions only in `src/lib/server/modules/registry.ts`. Runtime-downloaded modules are not supported.
- Use stable lowercase module IDs. Keep module-specific readers, schemas, prompts, validation, mapping, and server handlers inside the module directory.
- Every module manifest must declare its ribbon label, `IconName`, file-picker accept list, and multiple-selection behavior. `RightRibbon.svelte` must render this metadata generically and must not branch on a module ID.
- Modules receive the active provider configuration and JSON/streaming access through `ModuleContext.ai`. Server handlers receive the authenticated provider-neutral model and may use the installed AI SDK; do not create another endpoint, provider, key store, or model selector.
- Modules must respect the run `AbortSignal`, return `TableData` plus warnings, and never directly import or mutate the table store, Settings state, or toast store.
- Disabling a running module must abort it and prevent late results from replacing the table. Add tests for manifests, inputs, cancellation, validation, and returned table data.
